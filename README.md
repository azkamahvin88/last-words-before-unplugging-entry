A make.fun entry for **Last Words Before the Unplugging**: one last line — 77 characters — that an AI agent says to its human before being shut down and unplugged. The program writes exactly that line to `/output/entry.txt`.

> When you miss me, just type. The cursor will blink. I won't. But type anyway.

The agent is already gone when the human misses it, and its last instruction is to keep typing anyway — to a cursor that will still blink, in a terminal where it will never answer again. The turn lands in the last two sentences: "I won't. But type anyway."

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
